Operational behavior
--------------------
- If one or more effective verification methods are enabled, Android offers those methods.
- If all effective SMS/WhatsApp/SNA methods are disabled and Temporary Device Account is ON, Android automatically creates/reuses a LOCAL_DEVICE reader inside EP-DI.
- Device identity is based on a random installation UUID generated by the app; EP-DI persists only an HMAC.
- Temporary accounts use rolling inactivity expiry (default 30 days) and can be disabled through Admin → Subscribers.
- Successful later mobile verification can promote/merge the temporary reader into LOCAL_MOBILE.
