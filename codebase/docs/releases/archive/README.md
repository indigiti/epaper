# Historical release notes archive

Release-specific documentation removed from the crowded `codebase/` root is organized here by function. See [complete old-path index](../LEGACY-ROOT-INDEX.md) for every source → destination map.

- `build-manifests/` — historical build manifests
- `release-checks/` — historical regression outputs
- `updates/` — earlier version upgrade guides
- `rollbacks/` — older rollback instructions
- `installation-patches/` — legacy installers and hotfix notes
- `release-evidence/` — release diffs, schema/route evidence
- `feature-audits/` — historical UI, reader, mobile and processing reports
- `references/` — remaining product documentation
- `legacy-backups/` — old backup copies of application files; **not executable runtime files**

Stable current deployment/operator instructions stay at their existing source paths until a separate coordinated release, and legacy `SHA256SUMS` is unchanged. The independent `codebase/release/` snapshot remains untouched for historical parity checks. This is a source-tree presentation refactor, **not a rewrite of Git history**, so old commits continue to exist.
